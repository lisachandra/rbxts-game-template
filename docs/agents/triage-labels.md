# Triage Labels

Canonical workflow labels map directly to repo labels. Fetch them from gh.

Skill says role, use repo label.

`ready-for-agent` is Sandcastle pickup gate. Apply only when issue has enough context, acceptance criteria, scope boundaries, validation expectations.

Do not mark broad roadmap/pass/milestone/design-discovery issues `ready-for-agent`. Keep as any other label until split into narrow slices.
